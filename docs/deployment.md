# 공개 웹 배포

이 게임은 Node.js 서버와 SQLite를 사용합니다. GitHub Pages 같은 정적 호스팅으로는 회원가입·로그인·저장을 제공할 수 없습니다.

## Render 배포

저장소의 `render.yaml`은 Node 24 서버와 영구 디스크 1GB를 선언합니다. 영구 디스크를 위해 **유료 Starter 인스턴스**를 지정했습니다. 가격과 결제 조건은 Render 배포 화면에서 확인하세요. 무료 인스턴스의 임시 파일시스템으로 대체하면 재배포 시 계정과 진행 기록을 잃을 수 있습니다.

1. https://render.com/deploy?repo=https://github.com/moooncang/CG 에서 Render 계정으로 로그인합니다.
2. GitHub 저장소 접근을 허용하고 Blueprint 설정과 요금을 확인한 뒤 배포합니다.
3. 생성된 서비스의 공개 HTTPS 주소를 엽니다. 실제 주소는 Render가 배정하며 사전에 확정되지 않습니다.
4. 회원가입 → 초안 저장 → 로그아웃 → 재로그인으로 저장을 확인합니다. 재배포 후에도 계정이 유지되는지 확인하세요.

환경 변수 `COOKIE_SECURE=1`은 HTTPS 전용 로그인 쿠키를 설정합니다. `DATA_DIR=/var/data/creator-quest`에 데이터베이스를 보관합니다. `PORT`는 플랫폼 제공 값을 사용합니다. 서버를 여러 대로 확장하지 말고 단일 인스턴스로 운영하세요. 외부 데이터베이스로 이전하기 전에는 SQLite 디스크를 공유하지 않는 다중 인스턴스 운영을 지원하지 않습니다.

배포 설정은 준비되어 있으나 현재 작업 환경에는 Render 인증이나 배포 연결이 없습니다. 따라서 공개 서비스 생성·요금 결제·공개 URL 동작 확인은 아직 수행되지 않았습니다. 설정 파일 저장이나 GitHub 업로드는 실제 배포 완료를 뜻하지 않습니다.
