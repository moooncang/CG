# 크랙 작가 키우기

캐릭터 챗 제작자로 살아가는 3년을 플레이하는 한국어 웹 육성·경영 시뮬레이션입니다. 「게임개발 스토리」의 장르×소재 궁합·평가단·랭킹 구조와 「작가쨩 키우기」류 작가 육성 게임의 생활·멘탈 관리를 참고했습니다. 실제 크랙 서비스와 제휴하지 않으며 모든 수치·독자 반응·정산은 게임용 시뮬레이션입니다.

## 실행

Node.js 24 이상(`node:sqlite` 내장)에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start        # http://localhost:3000
npm run dev      # 서버 파일 변경 시 재시작
npm run build    # 구문 검사
npm test         # 엔진 단위 테스트 + 서버 통합 테스트
npm run build:pages   # GitHub Pages용 정적 빌드 (dist/)
```

서버 버전은 계정(회원가입/로그인)과 "회원가입 없이 브라우저에 저장" 두 가지 모드를 제공합니다. GitHub Pages 빌드는 브라우저 저장 모드만 제공합니다.

## 게임 구조

- **시간**: 1주 = 1턴. 1년 = 12개월 × 4주 = 48주, 기본 경력 3년(144주). 매주 체력이 회복되고 주 마감 시 정산·랭킹·이벤트가 발생합니다.
- **자원**: 코인, 체력(주간 리셋), 스트레스(95 이상으로 주를 넘기면 번아웃), 영감(기획에 소모, 영감 폭발 확률), 팔로워, 명성, 작가 레벨.
- **역량 5종**: 기획·프롬프트·이미지·연출·홍보. 작업과 훈련으로 경험치를 쌓고 레벨업. 기획 레벨로 장르·소재가 열립니다.
- **작품 제작**: 장르 10 × 소재 20 궁합(공개 후 도감에 영구 기록), 형태 4종(단일·다중·시뮬레이션·세계관), 규모 3종, 집중 포인트. 공정 4개(기획·프롬프트·이미지·소개)를 작업하면 진행률과 능력치 포인트(몰입·설정 유지·비주얼·매력)가 쌓이고, 50%에서 방향 선택이 나옵니다. 외주 4종, 비공개 테스트, 폐기.
- **공개와 평가**: 평가단 4명이 10점 만점으로 채점. 합계 32/40 이상은 명예의 전당. 매주 신규 유입·재방문·대화·수익·팔로워를 계산하고 14명의 라이벌 작가 작품과 함께 주간 TOP 10, 월간 TOP 5를 집계합니다. 홍보 3종, 공정별 업데이트, 시즌 2(리메이크), 완결 처리.
- **생활·성장**: 휴식 5종, 부업 5종(명성 해금), 장비 12종, 구독 4종(월초 결제), 작업실 5단계(슬롯·체력·임대료).
- **이벤트**: 랜덤 이벤트 35종 이상(악플·팬아트·정책 변경·라이벌 콜라보·출판 제안 등), 이달의 유행 장르·소재, 공모전, 번아웃, 연말 시상식 7개 부문.
- **엔딩과 다회차**: 엔딩 7종, 업적 18종. 점수에 따라 유산 포인트를 얻어 유산 상점에서 배경·특성·시작 보너스·세계관 조기 해금·경력 연장(5년) 등 15종을 해금합니다. 궁합 도감·업적·엔딩 컬렉션·회차 기록은 회차를 넘어 유지됩니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `data.js` | 장르·소재·궁합·특성·배경·장비·이벤트·엔딩 등 모든 콘텐츠 데이터 |
| `game.js` | 순수 함수 엔진 `act(state, action)`. 시드 난수로 재현 가능. 서버와 브라우저에서 동일 실행 |
| `public/app.js` | UI(작업실·제작·작품·랭킹·성장·생활·기록), 도트 작업실 Canvas, 모달, 저장소 어댑터 |
| `server.js` | 계정·세션·상태 저장(SQLite) HTTP 서버 |
| `scripts/build-pages.js` | GitHub Pages 정적 빌드 |
| `test/` | 엔진 단위 테스트(자동 플레이 3년 완주 포함)와 서버 통합 테스트 |

## 저장 및 운영

`data/game.db`에 계정·진행 상황·세션을 저장합니다. `DATA_DIR`로 저장 경로를 지정할 수 있습니다. 비밀번호는 랜덤 솔트와 scrypt로 해시하며, 로그인 세션은 HttpOnly/SameSite 쿠키를 사용합니다. HTTPS 배포 시 `COOKIE_SECURE=1`을 설정하세요. 이전 버전(v2) 저장 데이터는 새 메타 구조로 이전되며 진행 중이던 작품은 유산 1점으로 환산됩니다.
