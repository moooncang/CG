# 크랙 작가 키우기

캐릭터 챗 플랫폼 제작자로 살아가는 3년을 플레이하는 한국어 웹 육성·경영 시뮬레이션입니다. 실제 크랙의 공개 정책(크리에이터 미션, 크랙 온리, 크랙 오리지널, 월 정산, 운영 정책)과 제작 화면 구조를 조사해 게임으로 재해석했습니다. 실제 서비스와 제휴하지 않으며 모든 수치·독자 반응·정산은 게임용 시뮬레이션입니다.

## 실행

Node.js 24 이상(`node:sqlite` 내장)에서 별도 패키지 설치 없이 실행합니다.

```sh
npm start        # http://localhost:3000
npm run dev      # 서버 파일 변경 시 재시작
npm run build    # 구문 검사
npm test         # 엔진 단위 테스트 + 서버 통합 테스트
npm run build:pages   # GitHub Pages용 정적 빌드 (dist/)
```

서버 버전은 계정(회원가입/로그인)과 "회원가입 없이 브라우저에 저장" 두 가지 모드를 제공합니다. GitHub Pages 빌드는 브라우저 저장 모드만 제공합니다.

## 게임 구조

- **시간**: 1주 = 1턴, 1년 = 12개월 × 4주, 기본 3년. 매주 집계·랭킹·이벤트, 매월 초 정산(최소 1만원, 세금 3.3% 원천징수, 미만 시 이월).
- **크리에이터 사다리(실제 정책 기반)**: 일반 제작자 → 미션 참여 조건(전체 공개 작품 10 · 누적 대화 유저 1,000 · 팔로워 500) → 크리에이터 미션(누적 발화 10만) → 정식 크리에이터(크래커 사용액 1.5% 정산, 선물 90%) → 크랙 온리(24주 독점, 2.5%, 해외 소개) → 크랙 오리지널(미공개 스토리 심사, 구매금, 저작권 귀속, 후속작 시리즈 심사). 크리에이터 전에는 대화 정산이 없고 선물(70%)과 부업으로 버텨야 한다.
- **작품 만들기**: 캐릭터/스토리 유형, 실제 제작 화면과 같은 탭(프로필·스토리 설정·시작 설정·미디어·키워드북·단축어·스탯·엔딩·등록). 필수 탭을 100% 채우면 등록. 등록 정보: 장르 14, 타겟(여성향·남성향·전체), 대화 형태 4, 권장 모드 3(크래커 소모), 답변 길이 4, 이용자 층, 이미지 소스 4(퍼온 이미지는 제재 위험), 원작(2차 창작은 온리·오리지널 불가), 템플릿, 해시태그 3개(월별 메타 태그). 공개/링크 공개/비공개.
- **노출과 반응**: 신작 탭 2주 노출, 첫 주 좋아요 비율로 "반응 뜨거운 신작", 팔로워 알림, 타겟별 장르 선호(월별 변동), 메타 태그 검색, 갤러리 홍보탭·SNS·선물 이벤트·디스코드. 플레이·발화·좋아요·댓글(독자 댓글 풀, 악플, 댓글 닫기)·선물·크래커·정산을 작품별로 집계. 주간 랭킹(전체·여성향·남성향)과 월간 TOP 5를 16명의 라이벌 제작자(아키타입 8종, 크랙풍 작품명, ONLY/ORIGINAL 배지, 관계도)와 경쟁.
- **운영 정책**: 제재 4단계(경고 → 3일 → 7일 → 크리에이터 권한 박탈 = 즉시 엔딩). 외부 이미지·2차 창작·민감 표현 관련 이벤트.
- **생활·성장**: 체력(주간 리셋)·스트레스(번아웃)·영감(영감 폭발), 역량 5종, 장비 12, 구독 4, 작업실 5단계, 휴식 5, 부업 5.
- **대회·시상**: 홀수 달마다 공모전(태그 테마·장르·타겟 챌린지·스토리 대전·신인 발굴전), 2년차부터 11월 오리지널 집중 매입 대회. 작품당 참가 조건, 라이벌과 점수 경쟁, 대상/최우수/우수/입선 상금·인지도·수상작 배지. 연말 크랙 크리에이터 어워드 8개 부문.
- **게임 화면**: 홈의 작가 스튜디오 씬(기분·작업 상태·구매한 장비·트로피가 반영되는 벡터 일러스트), 갤러리 피드(라이벌 신작·오리지널 선정·잡담·대회 공고), 주간 결과 등급(S~D)과 순위 변동.
- **이벤트 70종+**(호재·악재): 정산 개편, 모델 업데이트, 하이퍼챗 출시, 크래커 가격 인상, 집중 매입 대회, 해외 서비스 소개, 운영자 상태 변경, 권리 침해 신고, 서열정리 글, 프롬 공유, 홍보탭 검열 논란, 라이벌 콜라보·DM·오리지널 입주 등.
- **엔딩 9종·업적 22종·독자 인사이트 15종(회차 간 유지)·명작 아카이브·유산 상점 16종(배경·특성·시작 보너스·패스트트랙·경력 연장)**. 세이브 슬롯 3개.

조사 출처와 반영 내역은 [크랙 생태계 조사 기록](docs/research-crack.md)에 정리했다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `data.js` | 장르·태그·타겟·모드·제작 탭·특성·배경·장비·이벤트·댓글·라이벌·엔딩·인사이트 등 모든 콘텐츠 데이터 |
| `game.js` | 순수 함수 엔진 `act(state, action)`. 시드 난수로 재현 가능. 서버와 브라우저에서 동일 실행 |
| `public/app.js` | 크랙 스튜디오풍 대시보드 UI(홈·제작·내 작품·랭킹·갤러리·성장·생활·기록), 모달, 세이브 슬롯, 저장소 어댑터 |
| `server.js` | 계정·세션·상태 저장(SQLite) HTTP 서버 |
| `scripts/build-pages.js` | GitHub Pages 정적 빌드 |
| `test/` | 엔진 단위 테스트(자동 플레이 3년 완주 포함)와 서버 통합 테스트 |

## 저장 및 운영

`data/game.db`에 계정·진행 상황·세션을 저장합니다. `DATA_DIR`로 저장 경로를 지정할 수 있습니다. 비밀번호는 랜덤 솔트와 scrypt로 해시하며, 로그인 세션은 HttpOnly/SameSite 쿠키를 사용합니다. HTTPS 배포 시 `COOKIE_SECURE=1`을 설정하세요. 이전 버전 저장 데이터는 호환되지 않아 새 프로필로 시작하며, 보유 유산은 유지됩니다.

## 참고 자료

뤼튼 갤러리의 공개 제작 글과 커뮤니티 가이드를 조사해 제작 공정, 테스트 부담, 홍보·업데이트, 독자 반응을 반영했습니다. 출처와 관찰/게임 규칙의 구분은 [조사 기록](docs/research-wrtn.md)에 정리했습니다. 공식 정책이나 전체 제작자를 대표하는 자료는 아닙니다.
