# Creator Quest

크랙 작가 생활에서 착안한 한국어 웹 시뮬레이션 게임입니다. 실제 크랙 서비스와 제휴하지 않으며, 실제 제작 가이드의 규칙을 검증·재현한 제품은 아닙니다.

## 실행

Node.js 24 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
cd /workspace/CG
npm start
```

기본 포트는 3000입니다. `PORT`로 변경할 수 있습니다. `npm run dev`는 서버 파일 변경 시 재시작합니다.

## 게임

초안(작품 형태·등장인물·장르·이미지 수·프롬프트·시작 설정·가이드)을 저장하고 제작 데스크에서 기획/프롬프트/이미지/소개 공정을 진행합니다. 테스트 후 공개하면 다음 날부터 독자 반응과 정산이 발생합니다. 반응·정산 리포트에서 유입과 재방문을 보고 홍보 또는 공정별 업데이트를 선택하세요. 역량 훈련, 피로 관리, 자금 확보용 의뢰와 홈페이지 테마를 지원합니다.

실제 이미지 생성·업로드와 LLM 채팅은 없습니다. 프롬프트 분량 보너스를 제거하고 제작 공정·역량·규모·테스트로 완성도를 계산합니다. 모든 수치·정산·독자 반응은 게임용 시뮬레이션입니다.

## 저장 및 운영

`data/game.db`에 계정·진행 상황·세션을 저장합니다. `DATA_DIR`로 저장 경로를 지정할 수 있습니다. 운영 시 이 디렉터리를 영속 볼륨에 두고 백업하세요. 비밀번호는 랜덤 솔트와 scrypt로 해시하며, 로그인 세션은 HttpOnly/SameSite 쿠키를 사용합니다. HTTPS 배포 시 `COOKIE_SECURE=1`을 설정하세요. 회원가입 속도 제한은 프로세스 단위이며 공개 서비스 규모의 분산 제한, 계정 복구, 운영 모니터링은 별도 작업입니다.

## 검증

```sh
npm run build
npm test
```

별도 번들링 없는 정적 JavaScript/CSS 앱이므로 build는 서버와 클라이언트 구문 검사입니다. 통합 테스트는 실제 임시 SQLite DB와 HTTP 서버로 가입, 중복 가입, 로그인 실패, 인증 차단, 잘못된 훈련 입력, 장르 잠금, 훈련, 테마 적용, 게시, 정산, 계정 격리, 로그아웃과 재로그인 후 저장 데이터 조회를 검증합니다.

## 참고 자료

뤼튼 갤러리의 공개 제작 글과 커뮤니티 가이드를 조사해 제작 공정, 테스트 부담, 홍보·업데이트, 독자 반응을 반영했습니다. 출처와 관찰/게임 규칙의 구분은 [조사 기록](docs/research-wrtn.md)에 정리했습니다. 공식 정책이나 전체 제작자를 대표하는 자료는 아닙니다.

## 공개 배포

[Render 배포 안내](docs/deployment.md)와 `render.yaml`을 제공합니다. 계정과 진행 기록을 보존하는 유료 영구 디스크 구성입니다. 배포 서비스 로그인과 요금 확인 후 활성화해야 공개 주소가 생성됩니다.

## GitHub Pages

`npm run build:pages`로 `dist/` 정적 버전을 생성합니다. main 푸시 시 `.github/workflows/pages.yml`이 검사 후 GitHub Pages에 배포합니다.

Pages 버전은 회원가입 없는 브라우저 저장 모드입니다. 서버 계정 인증은 제공하지 않으며, 기기·브라우저 간 저장을 공유하지 않습니다. 사이트 데이터 삭제 시 진행 기록도 삭제됩니다. Node 서버 버전의 계정 기능과 데이터는 그대로 유지됩니다.
