# Visual assets

- `studio-night.webp`: original image generated for this project using the image generation tool on 2026-10-12 (KST). WebP encoding via ImageMagick, approximately 410 KB. No Kairosoft art or third-party game screenshots are used.
- `studio-mark.svg`: original vector brand mark, consistent with the inline navigation icon set.

The studio illustration is atmospheric scenery. Actual owned equipment, studio tier, awards and mood are derived from saved game state and shown in the adjoining interface. Gameplay rules and save data remain in `game.js` and `data.js`.

- `pixel-symbols.svg`: preview sheet of 27 original pixel symbols. Source: `public/pixels.js`. Every sprite uses a 16 × 16 grid and a shared limited palette, drawn from SVG rectangles. Symbols identify action categories, resources, production modules and event types. General prose remains icon-free.
